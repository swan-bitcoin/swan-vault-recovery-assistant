    Change Configurations and Calculation

    Bitcoin wallets typically separate addresses for receiving transactions from those used to receive change from outgoing transactions. In most cases Tempura can calculate the correct change configuration from the wallet configuration. If you have an uncommon wallet or change configuration, uncheck the box and enter your change configuration.

    Tempura calculates the change configuration from the receive configuration if the receive descriptor paths end with /0/*. The calculated change configuration paths will end in /1/*.

    What is an Electrum Server?

    An Electrum server helps you connect to the Bitcoin network. It allows your wallet to quickly check balances, list transactions, and broadcast new ones. It can do this without downloading the entire Bitcoin blockchain. You trust the Electrum server to provide the correct balance and transaction information, and the server operator can potentially link your transactions to your IP address.

    If you have a trusted Electrum server (either on your own node or a trusted friend's), uncheck the box and enter its address.

    Using your own server is easy

    Enter your custom Electrum server in the format server:port. If the server uses SSL, you must specify it at the beginning.

    For example: ssl://electrum.satoshi.com:50001

    This is optional, and if left blank, the default server (Blockstream) will be used.

    Why would I change my network?

    For testing purposes, developers may want to use Tempura on networks where the coins involved do not have value.

    Each Bitcoin wallet should only be used with the network on which it was created. Tempura will typically detect mismatched wallet configuration and network selections.

    Understanding the Fee Rate

    Miners prioritize transactions based on this rate, which reflects how much is paid per "virtual byte" (a measure of transaction complexity). A higher fee rate increases the chance of a prompt confirmation, especially in periods of high network activity.

    Tempura automatically estimates the optimal fee rate to prioritize your transaction for inclusion in the next block. To set the fee rate manually, uncheck the box.
