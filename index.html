Automatic Change Descriptor Calculation

You only need to enter a change descriptor if it is non-standard. By default, Tempura automatically derives the change descriptor paths ending in /1/* from your receive descriptor if the receive descriptor paths end with /0/*, which is the most common format. The same goes for multipath descriptors of type <0;1>.
