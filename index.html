Welcome to Tempura
a simple recovery toolkit for bitcoin descriptor wallets with hardware keys

To begin, enter your receive descriptor or wallet configuration
Most wallets do not require a separate change descriptor
You can use your own (or a specific) electrum server if you prefer
Network: If this is not a bitcoin mainnet wallet, select a network
With the above configured, Tempura is ready to read your wallet
Enter a destination address to move funds out of this wallet
Select a fee rate for the transaction

With the above configured, Tempura is ready to begin recovering funds

"Create sweep PSBT" creates an unsigned transaction
sending all funds from the wallet to the destination address

You can paste a PSBT created by other software for signing or broadcast

"Check Devices" lists connected hardware signing devices

With one device connected, click "Sign" to add a signature to the PSBT

Once generated, a transaction signature can be used forever
until some bitcoin it spends is confirmed spent.

Click "Broadcast" to attempt to relay the transaction to bitcoin miners.

You may want to first copy the PSBT and verify it.
